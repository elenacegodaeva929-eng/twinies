# Twinies — сайт студии

Статический сайт: HTML, CSS, картинки. Никаких сборок.
Можно открыть `index.html` двойным кликом и посмотреть локально.

**Все файлы лежат в корне репозитория, папок нет.** Картинки тоже —
так загрузка работает в любом браузере и ничего не теряется.

---

## Что где лежит

| Файл | Что внутри | Кому трогать |
|---|---|---|
| **content.js** | Фаундеры, подразделения, сотрудники, фильмы, лента работ, контакты | **Главный файл для правок.** Клиент может сам |
| **index.html** | Каркас + заголовок вкладки и описание для поисковиков | Правится текст в отмеченных местах |
| styles.css | Цвета, шрифты, сетки, анимации | Только через дизайнера |
| app.js | Раскрытие карточек, окна, формы | Не трогать |
| favicon.svg / .png | Фиолетовая звезда — иконка вкладки | Только через дизайнера |
| *.png | Логотипы, сигилы подразделений, фото, афиши | Складывать рядом с остальными файлами |

## Как обновить сайт

### Поправить текст

1. Открыть репозиторий → кликнуть на `content.js`
2. Карандаш справа сверху → изменить
3. Внизу **Commit changes** → ещё раз **Commit changes**
4. Через 30–60 секунд правка на сайте. Если не видно — обновить страницу
   с `Cmd+Shift+R` (Mac) или `Ctrl+F5` (Windows), браузер кэширует.

### Заменить файл или добавить картинку

**Add file → Upload files** → перетащить файлы в окно браузера → **Commit changes**.
Файлы с теми же именами заменятся, новые добавятся.

Потом в `content.js` вписать имя файла: `photo: "kseniia.jpg"`

### Если сломалось

Вкладка **Commits** → найти момент до поломки → кнопка возврата.
История хранится вся, потерять ничего нельзя.

## Как править контент (инструкция для клиента)

Открыть **content.js**. Внутри всё подписано по-русски. Три правила:

1. Текст всегда внутри кавычек: `name: "Kseniia Klever"`
2. После строки — запятая, кроме последней в блоке.
3. Внутри текста двойные кавычки `"` не ставить — вместо них «ёлочки».

Чтобы **добавить сотрудника** — скопировать строку `{ name: … }` целиком,
вставить ниже и переписать. Чтобы убрать — удалить её вместе со скобками.

### Курсив для названий

По-английски названия фильмов и проектов пишут курсивом, а не в кавычках.
Чтобы сделать курсив, оберните название звёздочками:

```js
selected: "Director of the documentary *A Silk Thread* and the short film *Nothing Feels*.",
```

На сайте звёздочки пропадут, а название станет курсивным. Работает
в биографиях, в блоке Selected work, в достижениях и цитатах фаундеров
и в описании фильма. Все уже вписанные названия так и оформлены.

Для **трейлера** нужна ссылка в особом виде, обычная из адресной строки
не подойдёт:

- YouTube — `https://www.youtube.com/embed/КОД_ВИДЕО`
- Vimeo — `https://player.vimeo.com/video/НОМЕР`

## Формы

Статический сайт сам письма не отправляет. Сейчас обе формы собирают ответы
и открывают почтовую программу с готовым письмом.

Когда появятся гугл-формы — впишите ссылки в `content.js`
(`createForm` и `joinForm`), и кнопки поведут туда.

## Лучшие работы: куда класть материалы

Портфолио у каждого сотрудника больше нет — все лучшие работы собраны
в одной ленте внизу страницы Projects, и под каждой подписан автор.

### Как добавить работу

1. Залить картинку в репозиторий (Add file → Upload files)
2. В `content.js` найти блок `works` и вписать:

```js
{ img: "work-katya-01.jpg", by: "Katya Yakimova", alt: "" },
```

- `img` — имя файла
- `by` — имя автора **точно так**, как оно написано в блоке `team` выше.
  Тогда рядом сама подтянется его фотография-кружок. Если имя не совпадёт,
  подпись останется, а кружка не будет.
- `alt` — короткое описание для поисковиков, можно оставить пустым

Строк можно добавлять сколько угодно — лента сама разложится в колонки.

### Как называть файлы

Папки не нужны — имя файла само работает как папка:
`work-katya-01.jpg`, `work-ilya-01.jpg`, `film-nothing-feels.jpg`.
Всё лежит в корне, загружается перетаскиванием в любом браузере.

### Фотографии сотрудников

В репозитории лежат `photo-01.jpg` … `photo-16.jpg` — присланные фото,
обрезанные в квадрат 800×800, плюс `photo-a.jpg` и `photo-c.jpg` у фаундеров.
Все уже расставлены по людям. Имя файла вписывается в поле `photo`
у нужного человека в блоке `team`:

```js
photo: "photo-07.jpg",
```

Фото подтянется сразу в трёх местах: кружок в списке подразделения,
большая карточка во всплывающем окне и кружок автора под работой в ленте.
Чтобы добавить новое фото — залить файл и вписать его имя тем же способом.

### Размер файлов

| | |
|---|---|
| Работа в ленту | ширина 1400–1600 px, JPEG, 200–400 КБ |
| Фото человека | 800×800 px, JPEG, до 200 КБ |
| Афиша фильма | 1200×1800 px, JPEG, до 400 КБ |
| Видео | **в репозиторий не класть** — YouTube/Vimeo |

Лимиты GitHub Pages: репозиторий до 1 ГБ, сайт до 1 ГБ, трафик 100 ГБ в месяц.
Упираемся не в лимит, а в скорость загрузки у посетителя, поэтому картинки
перед заливкой лучше сжимать — squoosh.app или tinyjpg.com, бесплатно
прямо в браузере.
