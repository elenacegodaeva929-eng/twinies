# Twinies — сайт студии

Статический сайт: HTML, CSS, картинки. Никаких сборок и установок.
Можно открыть `index.html` двойным кликом и посмотреть локально.

---

## Что где лежит

| Файл | Что внутри | Кому трогать |
|---|---|---|
| **content.js** | Фаундеры, подразделения, сотрудники, фильмы, лента работ, контакты | **Главный файл для правок.** Клиент может сам |
| **index.html** | Каркас + заголовок вкладки и описание для поисковиков | Правится текст в отмеченных местах |
| styles.css | Цвета, шрифты, сетки, анимации | Только через дизайнера |
| app.js | Переходы, карточки, окна, формы | Не трогать |
| img/ | Логотипы, сигилы подразделений, фото, афиши | Складывать сюда новые |

## Как обновить сайт на GitHub

Репозиторий уже создан, Pages включён. Дальше всё делается в браузере.

### Поправить текст

1. Открыть репозиторий → кликнуть на `content.js`
2. Карандаш справа сверху → изменить текст
3. Внизу зелёная кнопка **Commit changes** → ещё раз **Commit changes**
4. Через 30–60 секунд правка на сайте. Если не видно — обновить страницу
   с `Cmd+Shift+R` (Mac) или `Ctrl+F5` (Windows), браузер кэширует.

### Заменить файл целиком

**Add file → Upload files** → перетащить новый файл с тем же именем → **Commit changes**.
Старый заменится.

### Добавить картинку

1. Зайти в папку `img` (клик по её названию)
2. **Add file → Upload files** → перетащить файлы → **Commit changes**
3. В `content.js` прописать путь: `photo: "img/kseniia.jpg"`

> Папки перетаскиваются только в Chrome. В Safari — заходите внутрь нужной
> папки и загружайте файлы там.

### Если сломалось

Вкладка **Commits** → найти момент до поломки → кнопка возврата.
История хранится вся, потерять ничего нельзя.

### Проверить, что сборка прошла

Вкладка **Actions** — там видно последний деплой. Зелёная галочка = всё ок,
красный крест = GitHub не смог собрать (чаще всего из-за опечатки в `content.js`).

## Как править контент (инструкция для клиента)

Открыть **content.js**. Внутри всё подписано по-русски. Три правила:

1. Текст всегда внутри кавычек: `name: "Kseniia Klever"`
2. После строки — запятая, кроме последней в блоке.
3. Внутри текста двойные кавычки `"` не ставить — вместо них «ёлочки».

Чтобы **добавить сотрудника** — скопировать строку `{ name: … }` целиком,
вставить ниже и переписать. Чтобы убрать — удалить её вместе со скобками.

Для **трейлера** нужна ссылка в особом виде, обычная из адресной строки
не подойдёт:

- YouTube — `https://www.youtube.com/embed/КОД_ВИДЕО`
- Vimeo — `https://player.vimeo.com/video/НОМЕР`

## Структура сайта

```
Главная
├── Hero — логотип, кристалл, описание студии
├── Founders — две карточки → отдельная страница с достижениями
├── Divisions — четыре сигила → страница подразделения с командой
├── Projects
│   ├── Our films — афиша + описание, трейлер в окне
│   └── Works by our twinies — лента работ, клик открывает картинку
└── Become a twinie — приглашение в команду

Create art — форма заявки в студию
Become a twinie — форма для желающих в команду
```

## Формы

Статический сайт сам письма не отправляет. Сейчас обе формы собирают ответы
и открывают почтовую программу с готовым письмом.

Когда появятся гугл-формы — впишите ссылки в `content.js`
(`createForm` и `joinForm`), и кнопки поведут туда. Форма-заглушка
исчезнет сама.
